# JavaScript To-Do List Application

An interactive To-Do List application built using HTML, CSS, and JavaScript.

The application allows users to manage daily tasks by adding new tasks, marking tasks as completed, deleting individual tasks, and clearing all tasks. It also tracks task counts and uses browser Local Storage to save tasks so they remain available after refreshing the page.

## Live Demo

View the live application here:

[JavaScript To-Do List](https://maryawino.github.io/javascript-todo-assignment/)

## Features

- Add new tasks.
- Mark tasks as completed using checkboxes.
- Delete individual tasks.
- Clear all tasks at once.
- Display the total number of tasks.
- Display the number of completed tasks.
- Validate empty task input.
- Save tasks using browser Local Storage.
- Restore saved tasks after refreshing the page.
- Display a message when there are no tasks.

## Technologies Used

- **HTML5** – Used to structure the application.
- **CSS3** – Used to style the application and make it responsive.
- **JavaScript** – Used to implement functionality and DOM manipulation.
- **Browser Local Storage** – Used to save and restore tasks.

## Installation and Usage

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/MaryAwino/javascript-todo-assignment.git
   ```

2. Navigate into the project folder:

   ```bash
   cd javascript-todo-assignment
   ```

3. Open `index.html` in your web browser.

No additional dependencies or installations are required.
